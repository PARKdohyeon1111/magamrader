## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 기능 1 |마감 레이더로 앞으로 6주동안 할일을 계산해서 여유,보통,바쁨,폭풍 4단계로 보여준다. |
| 기능 2 |선생님들꼐서는 수행평가 날짜를 정하기 전에 다른 마감과 겹치는지 확인하고 덜 바쁜 날짜를 추천받을수 있다.|
| 기능 3 |QR 코드로 반친구들과 일정을 간편하게 나눠줄수있다.|

**사용 방법**

1. 앱 주소에 접속합니다.
2.+버튼으로 수행평가를 추가할수있다.
3.반 공유 탭에서 qr을 만든후 친구들이 폰 카메라로 찍게해서 일정을 공유할수있다.
